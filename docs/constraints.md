# 不可回退约束

道理鱼 MCP 服务必须满足以下入口约束：

- 管理页面和 `/mcp` 都通过安装向导配置的独立 TCP 端口访问。
- FPK `app/ui/config` 的入口类型必须是 `url`，不能是 `iframe`；`iframe` 会生成 fnOS 桌面窗口。
- FPK 入口禁止声明 `gatewayPrefix`、`gatewaySocket` 或依赖飞牛统一网关。
- Token 管理必须是独立 `/tokens` 页面，不能退回插件页弹窗。
- 进入独立管理页即可管理平台；调用 Token 只调用 MCP。
- Token、插件目录、启用状态和插件配置必须位于应用数据目录，升级/重新安装默认保留；卸载必须提供保留或彻底清除选项。

如果需要修改入口，必须同时更新本文件、入口配置审计和 FPK 包内验收。
