# 运维说明

FPK 的默认服务端口为 `37421`，安装向导可改为其他端口；端口会保存到应用数据目录并由生命周期脚本传给服务，管理页面不提供端口修改入口。FPK 入口使用独立端口的浏览器 `url` 页面，不使用 `iframe` 桌面窗口、`gatewayPrefix` 或 `gatewaySocket`。监听地址由 `DAOLIYU_MCP_BIND` 控制，fnOS 生命周期脚本默认设为 `0.0.0.0`。

进入独立后台 `/` 可安装、配置、启停和卸载插件；独立 `/tokens` 页面只管理调用 Token。两个页面都不需要额外的系统管理密钥。ChatGPT 连接使用：

```text
http://<FNOS-IP>:37421/mcp
Authorization: Bearer <调用 Token>
```

`*` 范围会动态包含现在和以后安装并启用的所有插件；指定插件范围只暴露所选且已启用插件的工具。调用 Token 按用户要求以明文保存在 `auth-tokens.json` 中，文件权限为 0600，便于页面显示和复制；不要把任何密钥提交到插件包或截图。

Token、插件目录、启用状态和 `config.json` 都位于 `${TRIM_PKGVAR}/data`。升级和重新安装不覆盖这些数据；卸载向导默认保留，可选择“彻底清除全部应用数据”后再删除。单个插件卸载同样可选择保留或彻底清除；保留的数据在安装同 ID 插件时自动恢复。

插件安装、配置、启停和卸载都通过插件 ID 操作并立即影响新请求。首版不依赖统一网关，因此网关会话过期不会中断 MCP 端点；仍需在 NAS 防火墙或反向代理层限制服务端口来源。独立端口不等于匿名端口，不要只把 `IP:端口` 暴露给不可信网络。
